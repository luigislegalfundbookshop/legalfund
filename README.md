# Fundraising Analytics Dashboard

A comprehensive fundraising analytics dashboard built to analyze donation patterns, identify major gift opportunities, and optimize fundraising ROI.

## Project Overview

This dashboard provides:
- Anomaly detection for major gifts ($30K+ events)
- Donor segmentation analysis
- ROI optimization projections
- Interactive data visualization

## Files

- `index.html` - Main fundraising analytics dashboard
- `donor_segmentation_strategy.html` - Donor segment analysis
- `actionable_outreach_plan.html` - 30-day implementation plan
- `executive_summary.html` - Strategic overview
- `fundraising_roi_calculator.html` - ROI projections
- `anomaly_adjusted_analysis.py` - Data analysis script
- `complete_fundraising_data.csv` - Raw fundraising data

## Installation

1. Clone this repository
2. Open `index.html` in your web browser
3. No additional dependencies required

## Analysis Results

- **Baseline fundraising**: $3,255/day (excluding anomalies)
- **Major gift impact**: 6 events of $30K+ skewing metrics by 24.6%
- **ROI potential**: 23% revenue uplift with targeted outreach
- **Donor segments**: 4 distinct segments identified

## Dashboard Features

- Real-time fundraising metrics
- Event-driven fundraising analysis
- Donor segment visualization
- ROI calculator and projections
- Implementation timeline

## Data

Analysis based on 327 days of fundraising data including:
- Daily donation totals
- Event types (organizer, legal, media)
- Donor segmentation data
- Performance metrics
